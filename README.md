# Flatfy Listings Analysis

**Stack:** Python · pandas · Jupyter

How does data quality affect comparisons of listing prices?

## Analysis

Profile listings, check missing values and duplicates, and compare prices across listing segments.

## Run locally

1. Install dependencies with `python -m pip install -r requirements.txt`.
2. Place your authorized input files at the paths referenced in the notebook. Expected inputs: `data/flatfy_2019_sample.csv.gz`.
3. Open `analysis.ipynb` in Jupyter and run the cells from the repository root.

The input datasets and generated tables are excluded. The analysis requires inputs matching the original column schema.
